# 深度学习驱动的低纬电离层 F2 层临界频率预测

> 本科毕业设计 · 基于 LSTM 长短期记忆网络的电离层 foF2 逐小时预测
> 数据来源:IGS(国际 GNSS 服务)IONEX 电离层数据 · 2014–2025 共 **12 年** 时序
> 目标区域:低纬(中国华南沿海 / 南海,网格点 **20°N, 120°E**)

---

## 一、项目背景

电离层 F2 层临界频率(foF2)是空间天气学的重要指标:它决定了高频(HF)通信的最大可用频率(MUF),
并直接影响天波超视距雷达精度与 GNSS 电离层延迟修正。低纬地区受**磁赤道电动力学**影响显著,
存在明显的赤道电离异常(EIA),叠加昼夜变化、季节变化与 11 年太阳活动周期,变化极为复杂。

传统经验模型(如 IRI)对月均与年际变化表现良好,但遇到地磁暴等短时剧烈扰动时容易"过度平滑"而丢失高频波动。
本项目采用**数据驱动的单层 LSTM 网络**,完成 **IONEX 原始数据解析 → 长时序重建 → 深度学习建模 → 多尺度评估** 全流程。

## 二、核心结果

### 2.1 与基准模型的精度对比

测试集:2025 年全年独立测试集(约 8,000 小时,完全独立于训练集)

| 评价指标 | 本文 LSTM 模型 | 持续性基准模型 |
|:---|:---:|:---:|
| 均方根误差 RMSE (MHz) | **0.4822** | 0.9315 |
| 平均绝对误差 MAE (MHz) | **0.3406** | 0.6521 |
| 误差均值 (MHz) | ≈ 0(无显著偏倚) | — |
| 皮尔逊相关系数 R | **0.9897** | — |
| 决定系数 R² | **0.9795** | — |

> 持续性基准模型(Persistence)假设「下一时刻的值 = 当前时刻的观测值」,即 Y(t+1) = Y(t),
> 是时序预测中最常用的朴素对照。本文 LSTM 相比基准 **RMSE 降低约 48%、MAE 降低约 48%**,
> 相比文献中 LSTM-DNN 混合模型(平均相对精度约 82%)与 IRI 组合预报(磁平静期 RMSE 约 1.1 MHz)均具优势。

### 2.2 多时间尺度的预测精度

| 时间尺度 | RMSE (MHz) | MAE (MHz) | 说明 |
|:---|:---:|:---:|:---|
| 全年 2025 | 0.4822 | 0.3406 | 宏观整体水平 |
| 春季 3 月(春分) | 0.4553 | 0.3515 | 波动剧烈期 |
| 夏季 6 月(夏至) | 0.3578 | — | 全年最优 |
| 秋季 9 月(秋分) | 0.4535 | 0.3315 | 波动剧烈期 |
| 冬季 12 月(冬至) | 0.4246 | — | 最大差值 < 1.3741 MHz |
| 连续一周 | 0.4712 | 0.3345 | 昼夜交替追踪 |
| 连续 48 小时 | 0.4530 | — | 瞬时绝对差 < 0.8 MHz |

### 2.3 主要结论

- 模型准确复现电离层**「半年异常」**:春秋分整体及白天最大值显著高于夏至、冬至
- 能够快速响应每日 **「晨光突变」(Morning Surge)**,弥补传统经验模型在上升沿的滞后
- 误差具有清晰的物理可解释性:黎明(06:00–08:00)、黄昏(18:00 前后)误差上升(EIA 喷泉效应),
  春分秋分附近存在误差"暖色带";夜间复合衰减期精度高于全天平均
- 在地磁扰动活跃期(Kp > 4)出现负相暴、频值非线性骤降时,模型仅在初始下降有轻微滞后,
  随后迅速自我纠正,未出现长时间趋势分离

## 四、技术实现要点

### 4.1 IONEX 原始文件解析(DataExtract.m)

- 定位 `EPOCH OF CURRENT MAP` 帧头,提取 年/月/日/时 时间戳,并修复千禧年两位年份的写法
- 解析 `LAT/LON1/LON2/DLON` 数据块,按经纬度网格索引定位目标网格点(20°N, 120°E)
- IONEX 以整数压缩存储频值,×0.1 还原为 MHz;`≥ 900` 视为无效填充码,置为 NaN
- **时间对齐**:文件系统返回的文件顺序并非时间顺序,采用后置 `sort` 按绝对时间戳重组 12 年序列

### 4.2 数据预处理与特征工程(Data_Prepare.m)

- 长序列中的缺失值用 `fillmissing(...,'linear')` 线性插值填补
- **按真实年份切分:2014–2024 训练(11 年)/ 2025 盲测(1 年)** —— 时间跨期隔离,
  从根本上规避随机打乱划分造成的"未来数据泄露"
- Z-score 标准化,**μ、σ 仅由训练集计算**并落盘复用,测试集用同一组参数反归一化
- 构造 **24 小时滑动窗口**样本:`X = [t-23, …, t]`,`Y = t+1`(监督学习格式)

### 4.3 网络结构与训练配置(Train_LSTM.m)

```
sequenceInputLayer(1)
lstmLayer(64, 'OutputMode', 'last')
fullyConnectedLayer(1)
regressionLayer
```

训练配置:Adam 优化器 · MaxEpochs 20 · MiniBatchSize 256 · 梯度阈值 1(防梯度爆炸)·
初始学习率 0.005(分段衰减 piecewise,每 10 epoch ×0.2) · 共 9,360 轮次迭代,训练耗时约 1 分 42 秒

### 4.4 超参数消融实验

| 滑动窗口 | 隐藏层节点 | 验证集 RMSE (MHz) | 综合评估 |
|:---:|:---:|:---:|:---|
| 12 小时 | 64 | 0.6124 | 记忆长度不足,存在预报滞后 |
| 24 小时 | 32 | 0.5532 | 模型容量较小,欠拟合趋势明显 |
| **24 小时** | **64** | **0.4822** | **参数配置最优(本文选取)** |
| 24 小时 | 128 | 0.4955 | 参数过冗余,产生轻微过拟合 |
| 48 小时 | 64 | 0.4910 | 计算开销倍增,精度提升微弱 |

> 电离层变化受一天两次光照影响,故 24 小时窗口在物理上最契合其周期特性。

### 4.5 评估体系

RMSE / MAE / 误差均值 / 皮尔逊相关系数 R / 决定系数 R²
\+ **Persistence 基准对照** + 误差概率密度分布(正态拟合)
\+ 误差逐时(0–23 h)分布 + 误差「月份 × 小时」二维热力图

## 五、复现步骤

1. 从 IGS 数据中心(如 CDDIS / IGS 归档)下载各年份 IONEX 数据包,按年份放入 `2014/` … `2025/` 目录
2. 运行 `UnZipped.m` → 全部解压至 `foF2_Unzipped/`
3. 运行 `DataExtract.m` → 生成 `foF2_12years_data.mat` + 12 年全景趋势图
4. 运行 `Data_Prepare.m` → 生成 `LSTM_Prepared_Data.mat` 与 `norm_params.mat`
5. 运行 `Train_LSTM.m` → 训练网络,输出训练曲线并保存 `My_Trained_LSTM.mat`
6. 运行 `Evaluate_Model_Performance.m` → 得到精度指标与评估图
7. 运行 `Evaluate_2025_Timeline.m` → 生成全年 / 季节 / 一周 / 48 小时多尺度对比图
8. 运行 `new.m`(扰动期特写)与 `untitled.m`(误差时空热力图)

**运行环境**:MATLAB R2021a 或更高 · Deep Learning Toolbox

> 注意:`UnZipped.m` 与 `DataExtract.m` 中的输入/输出路径为作者本地路径,
> 复现时请先修改为你的实际路径。
